# RemoteKeys
Android keyboard (IME) that works as a Bluetooth keyboard + media remote for a PC.
Tabs: REMOTE (arrows, play, volume, speed), KEYS (QWERTY), PC (F-keys, Ctrl/Alt/Win, nav), CUSTOM (your buttons).
Top-right: PC/PHONE mode switch, and a globe to switch to another keyboard.

Build: push to GitHub -> Actions tab -> "Build APK" -> download artifact "RemoteKeys-apk".
